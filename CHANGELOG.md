## Drink Beer Refill 1.4.0-beta.3 (Minecraft 1.21.11)

### Changed

- Added Minecraft 1.21.11 support for Fabric and NeoForge.
- Updated Fabric API support to 0.141.6+1.21.11, NeoForge support to 21.11.45, and JEI recipe integration to 27.22.0.65.
- Updated item models and recipes for Minecraft 1.21.11 while preserving the existing gameplay, automation behavior, registry IDs, saved-data keys, configuration keys, and network payload IDs.

### Important

- Java 21 is required.
- Minecraft-version branches are independent. Cross-version world upgrades are not supported; back up your world before opening it with a different Minecraft version.
